# PHL244 Writing Assignment 2 — prep checklist

A single static page for tracking revision before PHL244 Writing Assignment 2
(Human Nature, Fall 2026): Hull on human nature, Davidson on rationality, and
Broome on rationality and reasons, with Williams on internal and external reasons.

Ticks and which groups are open are kept in localStorage.
Set in OpenDyslexic, bundled in `fonts/` (SIL Open Font License, see `fonts/OFL.txt`).

No build step and no dependencies. Open `index.html`, or run `python3 -m http.server 8000`.
